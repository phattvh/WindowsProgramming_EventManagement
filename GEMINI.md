# Project Guidelines & Rules

## Git Commit Invariants
- **Language**: All git commit messages MUST be written strictly in **English**. Never use Vietnamese (with or without accents) in commit messages.
- **Format**: Follow the Conventional Commits specification:
  - `feat(<scope>): <short imperative description>`
  - `fix(<scope>): <short imperative description>`
  - `refactor(<scope>): <short imperative description>`
  - `docs(<scope>): <short imperative description>`
  - `test(<scope>): <short imperative description>`
  - `chore(<scope>): <short imperative description>`
- **Branch Policy**: Never push directly to `origin/main`. Push only to designated feature/working branches (`phat`, `test`, `tri`, `hung`).
